# airpollutionmonitoringsystem
This project is used for monitoring pollution levels in the atmosphere. Built using an ESP8266 (NodeMCU), an SDS011 sensor and an LM35 temperature sensor, it sends the data to the OneM2M server and connects it to IIIT Hyderabad college website.
# OM2M-REST-APIs

# POSTMAN
* Download and install the POSTMAN REST client: http://www.postman.com

# POSTMAN_collection 
* The postman collections are inside "***postman-collections***" folder:
* REST-APIs --> postman-collections 

* Import the collections (APIs & Environment) ( in POSTMAN as explained in: https://apitransform.com/how-to-import-a-collection-into-postman/
